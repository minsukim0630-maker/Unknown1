# 포케슬론 트레이닝 (프로토타입)

포켓몬을 3년간 육성해 **포케슬론** 출전을 목표로 하는 육성 시뮬레이션.
육성 방식은 우마무스메를 참고했으며, 레이스는 없이 **트레이닝 / 휴식 / 외출** 3가지 행동만 존재한다.

> 현재 단계: 가상 캐릭터의 **트레이닝 파트**만 구현 (포케슬론 경기는 이후 단계)

## 실행

빌드 없이 `index.html`을 브라우저로 열면 된다.

```bash
node tests/simulate.js 300   # 밸런스 시뮬레이션 + 동작 검증
```

## 구현된 시스템

| 항목 | 내용 |
| --- | --- |
| 스탯 | 스피드 / 파워 / 테크닉 / 스태미나 / 점프, 각 상한 **1200** |
| 기간 | 3년 × 24턴 = **72턴** (매월 전반/후반) |
| 트레이닝 | 5종. 주 스탯 + 보조 스탯 상승, 체력 소모. 4회 사용마다 Lv업 (최대 Lv5) |
| 휴식 | 체력 회복 (+70 / +50 / +30 확률) |
| 외출 | 컨디션 상승 + 소량 체력 회복 |
| 체력 | 0~100. 낮을수록 트레이닝 실패 확률 상승 (실패 시 스탯·컨디션 하락, 대실패 존재) |
| 컨디션 | 절불조 ~ 절호조 5단계, 트레이닝 효율 -20% ~ +20% |
| 서포터 | 6명이 매 턴 트레이닝에 랜덤 배치. 함께하면 효과 상승 + 유대 상승. 유대 80 이상 + 득의 트레이닝이면 **우정 트레이닝** |
| 여름 합숙 | 2·3년차 7~8월, 모든 트레이닝 Lv5 |
| 랜덤 이벤트 | 행동 후 15% 확률, 일부는 선택지 존재 |
| 육성 대상 | 가상 포켓몬 3종 (종족별 초기 스탯·성장률 차이) |
| 평가 | 스탯별 랭크 (G ~ SS) + 종합 평가 |
| 저장 | 브라우저 localStorage 자동 저장 / 이어하기 |

### 트레이닝 상승치 공식

```
상승치 = 기본치(Lv) × 컨디션 배율 × (1 + 서포터 트레이닝 효과 합)
        × 우정 트레이닝 배율 × (1 + 0.05 × 서포터 수) × (1 + 종족 성장률)
```

## 파일 구조

```
index.html        화면 구성
css/style.css     스타일 (모바일 대응, 다크모드)
js/data.js        모든 밸런스 수치·데이터 (여기서 조정)
js/engine.js      육성 로직 (DOM 비의존, Node에서도 동작)
js/ui.js          화면 렌더링·입력 처리
tests/simulate.js 자동 플레이 시뮬레이션
```
